# 현재 범위에서 제외한 콘텐츠와 소유자 확인 사항

이 문서는 내부 기록이며 공개 빌드에 포함하지 않는다. 기존 6개 페이지 `/`, `/landing`, `/about`, `/overview`, `/services`, `/announcement`만 유지한다. 새 서비스 상세·가이드·사례와 해당 탐색 링크는 이번 발행 대상에서 제외한다.

| 대상 | 현재 처리 | 향후 검토 조건 |
|---|---|---|
| 연구 플랫폼·MVP·유지보수 상세 3개 | 신규 페이지·메뉴·내부 링크·sitemap 항목을 만들지 않음 | 콘텐츠 확장을 별도 요청한 경우 제공 범위·제외 항목·사실 근거를 다시 확인 |
| 가이드 3개와 가이드 목록 | 신규 페이지·링크·sitemap 항목을 만들지 않음 | 별도 콘텐츠 확장 범위와 검토 책임을 정한 뒤 작성 |
| Nero 플랫폼과 소살리토 사례 상세·사례 목록 | 기존 홈 포트폴리오만 유지, 독립 사례 발행 없음 | 프로젝트 성격, NERO 담당·제외 범위, 화면 공개 허가, 운영 상태와 근거 확인 |
| 서비스 허브 | 기존 `/services`의 Nero CARE 소개 유지 | 기존 URL의 의미를 바꾸는 작업은 별도 논의 |
| 독립 문의 페이지 | 생성하지 않음 | 기존 `/#contact` 및 원래 문의 흐름 유지 |
| H1·CSS·접근성 UI·새 메뉴 | 기존 소스를 보존하고 수정하지 않음 | 기존 H1 부재나 접근성 문제는 별도 개선 범위에서 검토 |
| 공고 전체 본문 최초 HTML | 원래 요약만 사전 렌더링, 전체 본문은 기존 JS 모달 유지 | 본문 확장·상세 URL·대체 UI는 별도 범위에서 검토 |
| 문의·API·알림·분석 개선 | 원래 코드를 보존하며 새 중복 차단·응답 필드·이벤트 변경 없음 | 회귀 검사에서 발견한 문제를 관측값과 함께 별도 개선 항목으로 기록 |
| 회사 주소·성과·후기·가격·납기·기관 관계 | 기존 공개 원문을 보존하고 새 주장을 추가하지 않음 | 정확성과 공개 허가, 과거 공고와 현재 표기의 관계를 소유자가 확인 |
| 저자·검토일·게시일 | 임의 값 생성 안 함 | 실제 검토 책임자·날짜가 확인된 경우만 적용 |
| llms.txt·RSS·IndexNow | 현재 구현 대상 아님 | 별도 요청과 검토 후 진행; 추천 지시나 검색·AI 인용 보장 금지 |

현재 범위에서 제외한 페이지는 미완성 상태로 공개 디렉터리에 복사하거나 sitemap에 넣지 않는다. `seo-kit/CONTENT_BLUEPRINT.md` 등 사용자 원본 제안서는 수정하지 않는다. 내용 확장 제안과 현재 발행 대상을 구분한다.
