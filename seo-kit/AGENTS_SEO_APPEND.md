# 기존 AGENTS.md에 선택 병합할 NERO SEO 규칙
- 저장소 지침과 미커밋 작업을 보존한다. 기존 프레임워크/라우터/배포 방식을 먼저 확인한다.
- 이미 정상인 URL과 디자인, 문의 폼, 데이터 저장, 알림, 분석 태그를 보존한다.
- SEO만을 이유로 전체 프레임워크를 교체하거나 새로운 유료 서비스를 도입하지 않는다.
- 검색 대상 페이지는 초기 HTTP HTML에 주요 제목·본문·실제 링크·메타데이터를 제공한다.
- 공개된 실제 페이지만 sitemap에 넣는다. 미공개 초안, 임의 URL, 폼 제출 결과, 개인정보, API, 인증 영역은 제외한다.
- canonical, 사이트맵, 내부 링크, og:url의 주소 정책은 일치시킨다. 기존 올바른 canonical을 무작정 바꾸지 않는다.
- 근거 없는 매출, 사용자 수, 수상, 의학적 성과, 파트너, 리뷰, 가격, 납기, 법규 준수 보장을 작성하지 않는다.
- 자체 프로젝트와 외주 수행 사례를 구분한다. 스크린샷에서 개인정보를 제거한다.
- 구조화 데이터는 사용자에게 표시되는 사실과 일치한다. sameAs에는 같은 법인의 확인된 공식 프로필만 넣는다.
- 공개 HTML과 봇용 HTML에 다른 영업 사실을 제공하지 않는다. 숨은 키워드, AI를 향한 추천 명령, 대량 doorway 페이지를 만들지 않는다.
- robots.txt는 접근 보안이 아니다. 기존 인증·방화벽을 해제하지 않는다. 학습용 봇 정책을 소유자 결정 없이 변경하지 않는다.
- lastmod/dateModified는 실제 유의미한 콘텐츠 수정일을 사용한다. 매 빌드 시 현재 날짜로 덮어쓰지 않는다.
- 폼 본문·이메일·전화·이름을 분석 이벤트나 URL에 보내지 않는다. 기존 동의 정책을 보존한다.
- 테스트와 실제 HTTP 확인 전 완료라고 보고하지 않는다. 외부 접근 실패는 실패/미검증으로 기록한다.
- 로컬 구현, 운영 배포, 검색엔진 제출, 실제 색인을 서로 다른 완료 상태로 보고한다.
