# Landing image slots

Place image files in this folder with the names below. The `/landing` page uses `AssetSlot` markup from `js/landing.js`, so adding a file with the matching name will replace the placeholder automatically.

## Hero product

- `hero-product-desktop.png` - 데스크톱 히어로 제품 이미지
- `hero-product-mobile.png` - 모바일 히어로 제품 이미지
- `hero-product.png` - 이전 히어로 이미지 파일, 현재 랜딩에서는 사용하지 않음

## Service cards

- `service-landing-page.png` - 전환형 랜딩·신청 페이지 화면
- `service-mvp-poc.png` - MVP 또는 PoC 제품 화면
- `service-web-service.png` - 운영형 웹서비스와 관리자 화면
- `service-mobile-app.png` - iOS·Android 앱서비스 화면

## Portfolio cards

- `portfolio-nero-mental-health.png` - Nero 정신건강 통합관리 플랫폼 앱·관리자 화면
- `portfolio-sausalito-commerce.png` - 소살리토 공식 온라인 사이트와 운영 관리자 화면

Legacy placeholders from the first landing draft can stay in this folder, but the current `/landing` page reads the names above.
